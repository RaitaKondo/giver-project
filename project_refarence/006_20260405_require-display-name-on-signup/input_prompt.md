# input_prompt

## ユーザー依頼の原文
今は表示名を入力してもemailの@前が表示名になるようになってる。フロントから適切に送られてるか確かめて。どんな状況でもfirebaeUidを表示させるようにはしたくない。表示名項目は必須にしてフロントもバックもバリデーション付けて。

## この作業で扱う対象
- 新規登録時の表示名受け渡し経路（フロント→Firebase→バックエンド同期）の確認
- 表示名必須バリデーションのフロント/バックエンド実装
- firebaseUid fallback を使わない表示名解決への変更

## 前提条件
- Firebase Auth を認証基盤として使用
- バックエンドで Firebase IDトークン同期時に users を upsert

## 制約事項
- 既存プロフィール更新や認証フローを壊さない
- 表示名を必須扱いにする

## 実施前の整理メモ
- 現在の normalizeDisplayName に firebaseUid fallback がある
- サインアップUIで表示名必須チェックが弱い可能性がある

## 実施方針
1. サインアップ実装とバックエンド同期ロジックを確認
2. 表示名必須バリデーションをフロント/バックエンドへ追加
3. firebaseUid fallback を除去し、安全な代替フォールバックへ変更
4. テスト実行

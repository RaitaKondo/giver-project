# input_prompt

## ユーザー依頼の原文
メール変更は「検証リンク完了後に反映」。そのほかはそのまま実行してください

## この作業で扱う対象
- メールアドレス変更（Firebase verifyBeforeUpdateEmail + 再認証）実装
- パスワード変更（Firebase updatePassword + 再認証）実装
- DB email を Firebase トークン同期経由で更新するためのバックエンド調整

## 前提条件
- 認証は Firebase Auth を使用
- バックエンドは ID トークン検証時に users を upsert 同期している
- 現在プロフィール更新APIで email を直接更新できる

## 制約事項
- メール変更は検証リンク完了後に反映すること
- パスワードはバックエンドに送らず Firebase SDK で処理すること
- 既存機能を壊さないこと

## 実施前の整理メモ
- email 直接更新経路を残すと整合性が崩れる
- メール変更直後は DB 反映されないため、検証完了後の再ログイン/再同期動線が必要

## 実施方針
1. バックエンドで profile update 時の email 直接更新を無効化
2. フロントにメール変更・パスワード変更セクション追加（再認証付き）
3. 変更後のリフレッシュ/再ログイン案内を追加
4. テスト・ビルド実行

# input_prompt

## ユーザー依頼の原文
mailアドレス変更の認証メールが届かないのはなぜ？

## この作業で扱う対象
- メール変更認証メール未着の原因候補整理
- 現行実装に基づく切り分け手順

## 前提条件
- フロントは Firebase `verifyBeforeUpdateEmail` を利用
- メール変更は再認証を通して実行

## 制約事項
- この作業では調査結果の提示のみ（実装変更なし）

## 実施前の整理メモ
- 送信先メールアドレスの誤認（新メール宛）が頻出
- Firebase 側制限/テンプレ設定/迷惑メール判定も要確認

## 実施方針
1. 現行コードでメール変更フローの実装事実を確認
2. 未着の代表原因を優先度順に整理
3. 確認手順を提示

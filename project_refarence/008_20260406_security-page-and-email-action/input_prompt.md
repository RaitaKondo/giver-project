# input_prompt

## ユーザー依頼の原文
認証メールは迷惑メールフォルダに届いてた。メール内の認証リンクをクリックすると動作するが認証後にトップページに繊維するように設定などはできない？
プロフィール編集画面のセキュリティ設定セクションだけど、新しいページに遷移して操作するようにしたい。
ここまでで懸念点はある？

## この作業で扱う対象
- Firebase メール変更リンク完了後の遷移制御可否
- セキュリティ設定を別ページ化する設計上の懸念点

## 前提条件
- メール変更は verifyBeforeUpdateEmail を利用
- セキュリティ設定は現在 MeProfilePage 内に実装済み

## 制約事項
- 本作業は設計相談であり、実装は未着手

## 実施前の整理メモ
- Firebase action handler 経由で continueUrl 指定が必要
- 遷移後の再認証状態・トークン更新導線を設計する必要あり

## 実施方針
1. 仕様可否を整理
2. 懸念点を優先度順で提示
3. 実装時の推奨手順を提示
